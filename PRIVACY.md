# R8Radio Privacy

R8Radio is built to support Run8 radio, ELD, and helper display features. This file explains, in plain language, what the app does on your PC.

## What R8Radio Does

- Reads Run8 live values so the radio, ELD, and display features can update.
- Opens local UDP helper tools for Run8 communication.
- Saves settings and logs under `%LOCALAPPDATA%\R8Radio`.
- Checks GitHub releases for app updates.
- Creates bug report packages only when you submit a bug report.
- Can include app logs or a screenshot in a bug report if you choose to attach them.

## What R8Radio Does Not Do

- Does not collect background telemetry.
- Does not scan your personal files.
- Does not upload logs or screenshots unless you submit a bug report.
- Does not install hidden services or startup tasks.
- Does not keep running silently after you close the app.
- Does not sell, share, or broker user data.

## Bug Reports

Bug reports are user-started. If you submit one, R8Radio may save a local report package and, when configured, send that package to the R8Radio support channel.

If app logs are included, they are meant for troubleshooting Run8 connection, startup, audio, UDP, HUD bridge, and ELD issues.
